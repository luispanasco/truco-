# Créditos del estilo Lorelei

- **Cabeza y cara** (`piezas.ts`): estilo [Lorelei](https://www.dicebear.com/styles/lorelei) de DiceBear, diseño de Lisa Wischofsky, licencia [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (dominio público). Se extrae con `pnpm --filter @truco/web avatares:lorelei` (`scripts/avatares-lorelei.mjs`).
- **Torso, ropa, sombreros y accesorios** (`propias.ts`): dibujos propios del proyecto, con el mismo trazo.
